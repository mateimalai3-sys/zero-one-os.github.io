Everything you need to know about ZERO ONE OS.

ZERO ONE OS is a Linux-based operating system project focused on creating a modern and customizable desktop experience.

The Release version is recommended for normal everyday use. Alpha and Beta builds are intended primarily for testing.

ZERO ONE is built around the flexibility of the Linux ecosystem, allowing you to customize your environment.

The ZERO ONE OS project is hosted on GitHub together with the website and project files.
